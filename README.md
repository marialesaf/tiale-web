# tiale — Invitaciones digitales

Sitio web de Tiale: catálogo de invitaciones digitales (bodas, XV años, baby shower y cumpleaños) con cotización por WhatsApp.

## Contenido
- `index.html` — el sitio completo (una sola página).
- `logo-indigo.png` / `logo-white.png` — logos de marca.
- `.nojekyll` — evita que GitHub Pages procese los archivos.

## Publicar con GitHub Pages
1. Sube estos archivos a un repositorio en GitHub.
2. Settings → Pages → Source: Deploy from a branch → rama `main` / carpeta `/root` → Save.
3. En 1–2 minutos el sitio queda en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
